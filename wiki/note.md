# Пост-действия после unique_icon

## Обязательная ручная проверка в браузере (по общим правилам проекта для UI)
- Запусти приложение (дев-сервер / wasm-сборку, которая рендерит Explorer дерево).
- Создай / открой файлы:
  - `script.js`
  - `face-layout.j2`
  - `help.md`
  - `data.json5`
  - `page.html`
  - `style.scss`
  - `face.pdf`
  - `logo.png`
  - `notes.txt`
  - файл без расширения
- Убедись визуально:
  - У .js и .j2 слева от имени — **разные** иконки (не пустой слот).
  - Иконки js/j2 **отличаются** друг от друга и от json/html/scss.
  - Все остальные перечисленные типы имеют свои иконки как раньше (регрессий нет).
  - Пустой слот для txt и без-расширения сохранён (колонки не съезжают).
- Проверь в desktop viewport и (если поддерживается) mobile/узком.

## Возможные доработки после визуальной проверки (если потребуется)
- Если текст "JS"/"J2" в иконках обрезан/смещён — подправить y и/или font-size в JsFileIcon / J2FileIcon (только в icons/files.rs).
- Если цвета недостаточно различимы на фоне — поменять fill (только эти два компонента).

## Дополнительно
- Полная интеграционная/визуальная проверка explorer tree лежит за пределами разрешённых для редактирования файлов на этом шаге.
- После визуальной приёмки можно коммитить (текущие изменения только в двух .rs + отчёты в wiki).

# Пост-действия после button_annotations

## Обязательная ручная проверка в браузере (по общим правилам проекта для UI-изменений + приёмке задачи)
- Запусти дев-сервер для WASM UI (обычно `trunk serve` из корня или `serve.bat` / `start.bat`).
- Открой приложение в браузере.
- Убедись, что слева есть activity bar с 7 кнопками (New game, Load game, Download, Prepare HTML, Prepare PDF, Split preview, Clear).
- Для **каждой** из 7 кнопок:
  - Наведи курсор и удержи неподвижно > 1.5 секунды.
  - Должен появиться DelayedTooltip с **точным** текстом, который был до изменений (см. строки в conf/src/api.rs).
  - Тултип исчезает при уходе курсора.
- Проверь в desktop viewport. (Mobile не обязателен для activity bar.)
- Убедись в отсутствии регрессий:
  - Кнопки работают (клик запускает те же действия).
  - Нет лишних тултипов.
  - Другие элементы (в explorer header NewFile/NewFolder) по-прежнему используют только title=, без delayed tooltip.

## Возможные доработки (только если проверка покажет проблему)
- Если текст тултипа не совпадает — проверить, что const в conf/src/api.rs и text=conf::ui::... в кнопке совпадают.
- Никаких изменений в CSS/логике не требуется по задаче.

## Дополнительно
- Полная визуальная/интеграционная проверка лежит на ручной проверке, т.к. правки только в строках (логика рендера tooltip'ов осталась нетронутой).
- После успешной hover-проверки можно коммитить.
- Сборка и unit-тесты уже зелёные: `cargo test -p deck_gen_wasm_conf -p deck_gen_wasm_ui`.

Дата: 2026-09-15
