# Note — доработка №1 (vscode_like_ui.md)

## Требуемые действия от пользователя
(пусто — данная доработка не добавляет новых ассетов, иконок или конфигов)

Все 3 пункта закрыты кодом:
- позиционирование меню Settings (bottom-align)
- динамические локализованные подписи смены темы
- белый фон страниц в генерируемых PDF (face/back + duplex)

## Проверка
- cargo test + trunk build пройдены для затронутых крейтов.
- Полная ручная проверка в браузере (после serve.bat) рекомендуется:
  1. Установить тёмную тему.
  2. Открыть меню Settings в нижней части бара → убедиться, что всё меню видно, его нижний левый угол совпадает с низом кнопки Settings.
  3. Переключать темы через пункт меню, закрывать/открывать меню заново → надпись меняется: "Сменить тему (светлая)", "(тёмная)", "(системная)".
  4. Выполнить Prepare PDF → открыть любой из сгенерированных PDF (deck-*.pdf, A4-*.pdf, monopoly*.pdf и т.п.) в превью → страницы должны быть белыми, содержимое видно (в т.ч. при тёмной теме приложения).
