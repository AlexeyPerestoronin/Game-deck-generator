# Пост-действия

1. Перезапусти или дождись пересборки UI (`serve.bat` / `trunk serve`) и обнови страницу жёстко (Ctrl+F5), чтобы сбросить CSS и WASM.
2. Открой preview `face.pdf` / `a4-duplex.pdf`: белый лист и **видимые карты**, не чёрные прямоугольники.
3. Проверь и в split, и без него.
4. В браузере я это не прокликивал: только `cargo test -p deck_gen_wasm --offline` (55 ok).
