# Что сделать с вашей стороны

1. Пересобрать WASM (`start.bat` / `trunk serve`) и жёстко обновить страницу.
2. Загрузить PDF и картинки, нажать F5: они должны остаться в дереве и открываться в Preview.
3. Clear workspace должен убирать и бинарники (после reload их тоже нет).
4. Браузер я не открывал — только unit-тесты и wasm32 check.
5. В DevTools → Application → IndexedDB → `deck_gen_wasm` можно увидеть store `binaries`.
6. Старые сессии без IDB просто поднимут текст; PDF/картинки нужно загрузить ещё раз один раз, дальше они уже пишутся в IDB.
