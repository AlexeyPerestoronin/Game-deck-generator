# Пост-действия

1. Перезапусти или дождись пересборки UI (`serve.bat` / `trunk serve`) и обнови страницу http://127.0.0.1:8080.
2. На левой полоске нажми новую кнопку (две колонки, подсказка «Split for preview»):
   - рабочая область делится пополам, кнопка синяя;
   - открытые Preview уезжают направо, файлы остаются слева;
   - если Preview не было — справа пусто.
3. При включённом split открой html/md/pdf/картинку в дереве: файл слева, Preview справа (если его ещё не было).
4. Нажми кнопку ещё раз: одна лента вкладок, кнопка снова серая; левые вкладки на месте, правые Preview тоже в общем списке.
5. В браузере я это не прокликивал: только `cargo test -p deck_gen_wasm --offline` (54 ok).
