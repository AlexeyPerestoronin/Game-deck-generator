# Что сделать с вашей стороны

1. Пересобрать и открыть WASM-приложение (`start.bat` / `trunk serve`) и обновить страницу — без этого UI со старым бандлом.
2. Проверить в браузере (я не гонял UI руками, только unit-тесты и `cargo check` под wasm32):
   - Load Game: папка с `.jpg` / `.png` / `.icon` ≤ 100 МБ копируется в `games/`.
   - Load Game: картинка > 100 МБ — модалка с именем файла, папка не ставится.
   - ПКМ по папке → `load file(s)`: выбор нескольких файлов из `ALLOWED_EXTENSIONS` + картинок в эту папку.
   - ПКМ по картинке → Preview.
3. Картинки (как PDF) **не сохраняются в localStorage**. После reload сессии их нужно загрузить снова; в ZIP-скачивании они есть, пока вкладка жива.
4. Кроме `jpg` / `png` / `icon` приняты `jpeg` и `ico` (те же форматы). Если нужен строго только `.icon` без `.ico` — напишите.
