# Пост-действия

1. Перезапусти или дождись пересборки UI (`serve.bat` / `trunk serve`) и обнови страницу http://127.0.0.1:8080.
2. Включи `split for preview` (синяя кнопка на левой полоске).
3. Открой PDF колоды (например `_autogenerated/.../face.pdf` или `a4-duplex.pdf`): справа должен быть белый лист с картами, не чёрный экран.
4. Открой preview нескольких разных файлов (pdf / html / md) и перещёлкивай вкладки справа — содержимое должно совпадать с выбранной вкладкой, а не с последней открытой.
5. В браузере я это не прокликивал: только `cargo test -p deck_gen_wasm --offline` (55 ok).
