# Что сделать с вашей стороны

1. Пересоберите и перезапустите Trunk (`serve.bat`). Старый `dist/user-help.md/` (каталог) больше не нужен.
2. Один раз сбросьте отравленный help: удалите в дереве `deck_gen_wasm/user-help.md` **или** ключ `deck_gen_wasm.session` в Local Storage и обновите страницу. Иначе WASM увидит уже лежащий HTML и раньше не перекачивал его (теперь HTML считается «надо скачать снова», но надёжнее сбросить сессию).
3. Чтобы GitHub был основным источником, запушьте актуальный `deck_gen_wasm/user-help.md` в `master`. Пока raw 404, локально подставится Markdown, вшитый в WASM при сборке.
