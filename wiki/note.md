# Пост-действия

1. Перезапусти или дождись пересборки UI (`serve.bat` / `trunk serve`) и обнови страницу http://127.0.0.1:8080.
2. Проверь руками в дереве Games:
   - ПКМ по файлу → `copy` → ПКМ по папке → `past`;
   - повторный `copy` снимает синюю метку;
   - Ctrl+ЛКМ по нескольким строкам (дети выбранной папки тоже подсвечены) → ПКМ → `copy` → `past` в другую папку;
   - пункт `copy` в меню слегка синий, пока элемент в плане.
3. В браузере я это не прокликивал: только `cargo test -p deck_gen_wasm`.
