# Note — доработка №2 (vscode_like_ui.md)

## Выполненные доработки
1. PDF preview: чёрные страницы → белые (через color-scheme:light на обёртке iframe в preview, строго внутри deck_gen_wasm).
2. Секции Local/Global в боковой панели Games:
   - теперь по умолчанию делят высоту панели 50/50;
   - drag ползунка меняет относительные размеры секций (а не скроллит).

## Требуемые действия от пользователя (рекомендуется)
Полная ручная верификация в браузере (после `serve.bat`):
1. Открыть приложение.
2. Нажать кнопку **Games** на activity bar → левая панель показывает Local + Global.
3. Убедиться, что секции занимают всю доступную высоту поровну (по умолчанию).
4. Потянуть за разделитель между Local и Global → пропорции меняются, содержимое не скроллится при перемещении ползунка.
5. Загрузить/сгенерировать PDF (Prepare Pdf), открыть превью любого *.pdf (через контекстное меню Preview) — страницы должны быть белыми, контент читаем (проверить и в тёмной теме приложения).
6. Переключить Explorer/Games/Hidden — поведение панели и ресайз ширины без регрессий.

Если визуально всё ок — задача закрыта. Unit-тесты + сборка (cargo test -p deck_gen_wasm_ui, trunk build) пройдены.
