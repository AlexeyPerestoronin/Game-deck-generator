# Задача
Необходимо добавить возможность генерации игровых колод при помощи AI.

Базовый алгоритм работы:
1. пользователь нажимает кнопку `AI-Deck Generation` (далее Кнопка)
2. в рабочей области появляется файл `prompt.md` с предустановленным содержанием

Важные моменты:
Целевой AI: будет определён в дальнейшем, поэтому всё что необходимо это создать сигнатуру функции, которая будет отправлять запросы через API к выбранному AI и возвращать его ответ: `fn ask_ai(prompt: String) -> String`.
