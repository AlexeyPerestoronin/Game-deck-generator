# Задача
Необходимо поддержать возможность копирования и вставки существующих файлов и папок.

Алгоритм копирования/вставки:
- ПКМ на выбранных папках/файлах для копирования
- выбор пункта меню `copy`
- ПКМ на целевой папке в которую необходимо скопировать выбранные элементы
- выбор пункта меню `past`

Важные моменты:
- ПКМ меню для файлов должно расшириться опцией `copy`:
  - `copy` – копировать данный файл
- ПКМ меню для папок должно расшириться опциями `copy` и `past`
  - `copy` - копировать данную папку
  - `past` - вставить в данную папку
- должно быть возможно массовое копирование множества папок и файлов, одним из следующих способов:
  - №1: ПКМ каждой папке и файле, которые необходимо скопировать и выбор `copy` → ПКМ на папке куда нужно скопировать и выбор `past`
  - №2: с зажатым Ctrl ЛКМ по файлам и папкам, которые нужно скопировать (выбираем множество) → ПКМ по любой папке или файлу и выбор `copy` (выбранное множество помечается как копируемое) → ПКМ на папке куда нужно скопировать и выбор `past` (выбранное множество элементов копируется в эту папку)

- важно отметить, что на текущий момент возможность множественного выбора элементов в файлов системе не реализована → её нужно реализовать;
  - множественный выбор должен сказываться на визуальной компоненте выбранных элементов (как это выглядит в VSCode), причём выбор папки должен сказываться на визуальной компоненте всех её дочерних элементов, а не только на ней самой;
  - выбор элементов для копирования в файловой системе не должен приводить к копированию выбранного элемента в промежуточный буфер → выбранный элемент должен лишь помечаться как запланированный для копирования;
    - после того, как выбранные элементы были скопированы, соответствующая метка должна сниматься
    - также метку должно быть возможно снять повторным нажатием на `copy` в ПКМ меню элемента, копировать который более не нужно
      - если элемент уже запланирован для копирования, но ещё не скопирован, то должна меняться не только визуальная компонента в дереве локальной файловой системы, но и меняться стиль элемента в ПКМ меню - данный пункт должен начать немного подсвечиваться синим
