# Задача: рефакторинг крейта `deck_gen_wasm`

Необходимо произвести рефакторинг Rust кода крейта `deck_gen_wasm`.
Базовые правила для рефакторинга ищи в `wiki\prompts\refactoring-rules.md`.

Специальные цели текущего рефакторинга:
1. Обрати особое внимание на избыточность → если код можно сделать меньше и компактнее → нужно внести предложение по исправлению.
2. Обрати особое внимание на модульность → если где-то нарушается принцип единственности ответственности → нужно внести предложение по исправлению.
3. Обрати особе внимание на мёртвый код → если такой есть, то сообщи об этом в отчёте (удалим).
4. Убедись в правильности использования api из `deck_gen` (см. `deck_gen\src\lib.rs`)

# Особые указания
1. Какой код использовать для анализа:
   - `deck_gen_wasm`
   - `deck_gen\src\lib.rs`
   - прочие файлы и папки репозитория ИГНОРИРУЙ;
2. Код менять ЗАПРЕЩЕНО → только анализ и отчёт.
3. Подробный отчёт о проделанной работе запиши в `wiki\note.md`, примерно в таком формате:
    ```
    # Рефакторинг №-X: «суть проблемы»
    Описание проблемы:
    ...

    Предлагаемые решение:
    Решение №1: описание ...
    Решение №2: описание ...
    ...
    Решение №3: описание ...

    Сравнительная таблица предлагаемых решений:
    <таблица сравнительного анализа>

    (если решение только одно, то нужно объяснить причину почему другие решения не приемлемы)

    # Ваше заключение:
    (глава для меня, где я напишу своё решение по каждому из пунктов)
    ```
    Прочитав твой отчёт я вынесу заключение по каждому пункту (возможно добавлю свои) и потому уже будем производить работу по рефакторингу.
