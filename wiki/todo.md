# Задача
Необходимо произвести рефакторинг Rust кода крейта `deck_gen_wasm/fs`.
Базовые правила для рефакторинга ищи в `wiki\prompts\refactoring-rules.md`.

Специальные цели текущего рефакторинга:
1. Найти api-методы, который экспортируются, однако не используются внешними потребителями (их нужно удалить из публичного api).
2. Предложить, как можно избавить от необходимости предоставлять во вне `vfs::Vfs`, `vfs_fs::VfsFs` и оставить только `vfs::Node` (в идеале api должно предоставлять только функции вроде `mkdir`, `crate_file` и т.д. всё необходимо для работы с файловой системой + `vfs::Node` в качестве базового элемента файловой системы);
3. Предложить как можно избавиться от кода, предназначенного специально для работы с бинарными файлами (`visit_binaries`, `restore_binaries`) → api должен предоставлять возможность работы с файлами в общем смысле, тогда как определение типа файла целевого и, соответственно, способа работы с ним должно быть задаче вызывающего кода потребителей.

# Особые указания
1. Какой код использовать для анализа:
   - папка `deck_game_wasm`
   - прочие файлы и папки репозитория ИГНОРИРУЙ;
2. Код менять ЗАПРЕЩЕНО → только анализ и отчёт.
3. Подробный отчёт о проделанной работе запиши в `wiki\note.md`, примерно в таком формате:
    ```
    # Рефакторинг №-X: «суть проблемы»
    Описание проблемы:
    ...

    Предлагаемые решение:
    Решение №1: описание ...
    Решение №2: описание ...
    ...
    Решение №3: описание ...

    Сравнительная таблица предлагаемых решений:
    <таблица сравнительного анализа>

    (если решение только одно, то нужно объяснить причину почему другие решения не приемлемы)

    Ваше заключение: (утверждаю/не утверждаю)
    ```
    Прочитав твоё отчёт я вынесу решение по каждому пункту (возможно добавлю свои) и потому уже будем производить работу по рефакторингу.
