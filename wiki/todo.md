# Задача
Необходимо произвести рефакторинг Rust кода крейта `deck_gen_wasm`.
Базовые правила для рефакторинга ищи в `wiki\prompts\refactoring-rules.md`.

Специальные цели текущего рефакторинга:
1. Найти места кода для которых возможно более простая реализация (т.е. присутствует чрезмерное переусложнение);
2. Найти места кода для которых возможно выделить общую логику, которую можно вынести в отдельный модуль.
3. Найти узкие места кода негативно сказывающиеся на производительности:
    - не оптимальные циклы
    - не эффективная передача аргументов
    - возможная параллелизация выполнения
    - что-нибудь ещё...

# Особые указания
1. Какой код использовать для анализа:
   - крейт `deck_game_wasm`
   - прочие файлы и папки репозитория ИГНОРИРУЙ;
2. Код менять ЗАПРЕЩЕНО → только анализ и отчёт.
3. Подробный отчёт о проделанной работе запиши в `wiki\note.md`, примерно в таком формате:
    ```
    # Рефакторинг №-X: «суть проблемы»
    Описание проблемы:
    ...

    Предлагаемое решение:
    ...

    Ожидаемый эффект:
    ...

    Ваше решение: (подтверждают/неподтверждаю)
    ```
    Прочитав твоё отчёт я вынесу решение по каждому пункту (возможно добавлю свои) и потому уже будем производить работу по рефакторингу.
