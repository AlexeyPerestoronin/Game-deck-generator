# Задача
Сделать так, чтобы при первичной загрузки сайта пользователю в preview открывался файлл `deck_gen_wasm\user-help.md`, загружаемый из master ветки из git-hub (как это уже делается для других данных из git-hub).
Также неоходимо наполнить user-help.md информацией обясняющей новому пользователю для чего нужен этот сайт и как им пользоваться, с описаем доступных кнопок, и базового pipeline работы.
Пиши кратко: user-help.md должен быть не больше 100 строк.

## Задача на доработку №1
Что необходимо исправить:
1. user-help.md должен скачиваться, если его ещё нет в файловой системе;
2. user-help.md должен открываться в preview, если ещё не открыта ни одна вкладка;
3. index.html не должен копировать данные связанные с играми (../games/) → таковые данные должны загружаться с GitHub и, если в процессе этого произойдёт ошибка, то выводить модальное окно с предупреждением.

## Задача на доработку №2
Что необходимо исправить:
1. user-help.md не должен получать с github → пусть хранится локально
2. user-help.md в локальной файловой системе должен храниться в самом корне

# Особые указания
1. Какой код использовать для анализа:
   - крейт `deck_game_wasm`
   - прочие файлы и папки репозитория ИГНОРИРУЙ;
2. Как убедиться в правильности решения:
   - крейты, код которых подвергался изменениям, должны проходить сборку и проверку локальными unit-тестами;
3. Как правильно писать код:
   - этап-1: необходимо решить поставленную задачу и убедиться в её работоспособнои требуемым образом;
       - код необходимо писать простой, понятный и прямолинейный, без сложных абстракций;
       - если логика кода сложная, но позволяет написать простые unit-тесты для проверки, их надо написать;
   - этап-2: когда поставленная задача будет решена, код, созданный и зафиксированный на этапе-1, необходимо отрефакторить согласно правилам записанным в `wiki\prompts\refactoring-rules.md`
       - при организации кода придерживайся стиля той кодовой базы в которую вносишь изменения;
4. Краткий отчёт (50-100 строк) о проделанной работе в формате `было→стало(почему)` напиши в `wiki\result.md`.
5. Если какие-то пост-действия требуются от меня напиши их в `wiki\note.md`.
