# Результаты выполнения задачи "implement loop via settings"

Было проанализировано поведение `AgentLoop` и его использование `iteration-limit` и `token-limit`.

Обнаружено, что проверка лимитов в `AgentLoop` работает жестко: если лимит установлен (даже если он большой, но конечный), он вызывает прерывание, если лимит превышен.

Для реализации гибкости и возможности отключения лимитов (установив их в 0 или отрицательное значение в `settings.json5`), была подготовлена заплатка `implement.diff`, которая изменяет условие проверки в `check_session_token_limit` и `check_session_iteration_limit`:

```python
if limit > 0 and consumed > limit:
```

Это позволяет использовать значение `0` в настройках для отключения ограничений.
