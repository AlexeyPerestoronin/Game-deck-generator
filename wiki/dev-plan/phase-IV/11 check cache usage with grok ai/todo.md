# Задача: cache is absent
Необходимо проанализировать код в файле `tools\harness\agents\spacex_ai.py` и дать заключение по следующему вопросу: верно ли написана логика с точки зрения использования cache для сессии для stateless агента.

Причина по которой появилась эта задача в том, что при анализе лога после выполнения какой-либо задачи, `cached tokens` всегда нулевой.

В качестве результатов я ожидаю один из следующих результатов:
1. всё написано правильно → нужно объяснить почему `cached tokens` всегда нулевой;
2. логика написана правильно (сообщения попадают в кэш) не подсчёт кэшированных токенов не верный → нужно исправить;
3. логика написана не правильно (сообщения не попадают в кэш) → нужно исправить.

# Проверка решения
В качестве проверки проанализируй файлы в `WiKi/templates` и отформатируй каждый с целью улучшить качество шаблона (можно добавлять поля, писать указания, да что угодно, главно чтобы шаблоны были краткими и ячными (не более 150 строк)).
А по завершении я эту проверю не только задачу но и лог, чтобы удостовериться что основная задача была решена корректно и cached токены учитываются в статистике.

# Дополнительные указания
1. О результатах отпишись в `result.md` в формате `было→стало(почему)` (создай файл в той же папке где и `todo.md` для задачи).
2. Если от меня требуются какие-то действия, то пиши их в `note.md` (создай файл в той же папке где и `todo.md` для задачи).
3. Экономь токены:
   - читай минимально необходимый объём информации для решения задачи;
   - изменения в файлы вноси через patch.
