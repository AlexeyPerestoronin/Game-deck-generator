# Роль
Ты профессиональный разработчик (`см. WiKi/harness/roles/senior-developer.md`).

# Задача
Создать `todo-<task-short-name>.md` в котором описать dev-задачу на перенос python-реализации harness на чистый Rust с архитектурными улучшениями.

Базовая архитектура должна быть сохранена, за исключением следующих моментов:
1. Tools должны быть реализованы в рамках отдельных подключаемых модулей, классифицированные по категориям (работа с файловой системой, работа с git, работа с командной строкой, и т.д.)
2. Должен быть отдельный модуль ответственный за чтение и файла конфигурации + файл конфигурации `./harness/harness.json5`
3. Интерфейс запуска через CLI должен быть таким:
    ```
    harness.exe --help → показывает справку в командной строки
    harness.exe
        <--conf harness.json5> → опциональный параметр, определяющий где искать файл конфигурации (по умолчанию искать из cwd запуска)
        --prompt "user prompt..." → стартовый запрос пользователя
        --dump "path to dump file" → продолжение работы с dump-файла (не может быть задан вместе с --prompt)
    ```

# Дополнительные указания
1. Шаблон оформления результата смотри `WiKi/templates/development.md`
2. Результаты в `todo-<task-short-name>.md` рядом с `investigation.md`.
3. Код не запускай: только исследование и формулировка результата.
4. Экономь токены: читай минимум необходимого; правки вноси через patch.
