# Задача
Доработать задачу `todo-harness-loop-via-rust.md` по следующим пунктам:

## отдельный крейт conf

Необходимо создать отдельный крейт (`harness/crates/conf/Cargo.toml`) ответственный за чтение файла конфигурации (`harness.json`).
Особенности:
1. Только этот крейт может читать файл конфигурации → все остальные крейты используют его для получения соответствующих настроек.
2. Все ключи по которым читаются значения в `harness.json`, а также значения по умолчанию, если таковые имеются, должны быть записаны в отдельном модуле `harness/crates/conf/str/keys.rs` для удобства управления и изменения.
3. команда `harness.exe --conf-new <path-to-new-conf-file>` должна создавать новый файл конфигурации в максимально полном наполнении: все доступные команды, подписи комментариев к ним, значения по умолчанию, заглушки в случае, когда некоторые значения необходимо явно определить вручную.

## API-KEY ключ в файл конфигурирования моделей
Во всех файла конфигурации моделей должен быть ключ "api-key", который задаёт путь до файла с ключом, либо содержит ключ так таковой в виде строки. Параметр должен быть обязательным.
