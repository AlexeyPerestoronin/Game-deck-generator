# Описание задачи
Сейчас в модуле `projects\deck_gen_wasm\modules\ai` есть набор "боевых" тестов предназначенных для запуска пользователем (см. `projects\deck_gen_wasm\modules\ai\src\live.rs`). Необходимо вынести эти тесты в рамках отдельного модуля `projects\deck_gen_wasm\modules\ai_tests`, который будет предназначаться только для тестирования посредствам ручного запуска пользователем (т.к. для этого будет необходимо вводить API ключ). Данный модуль исключительно для ручных unit-тестов, что означает, что он не должен участвовать в сборке deck_gen_wasm, однако успешный прогон имеющихся там тестов должен гарантировать корректность работы в браузере.

## Моменты, которые необходимо учесть:
### №1
Файлы конфигураций для моделей, которые сейчас хранятся в `projects/deck_gen_wasm/modules/ai/bundled/<model-name>.json5` необходимо перенести внутрь нового тестового модуля и исключить их использование из deck_gen_wasm, т.к. теперь они должны будут предназначаться только для пользовательского тестирования.

В dec_gen_wasm в режиме реальной работы (в браузере) файлы конфигурации должны извлекаться из `https://github.com/AlexeyPerestoronin/Deck-Games/tree/master/Templates/ai-settings`, именно там теперь лежат все файлы связанные с ai, которые на текущий момент находятся в локальной папке `projects/deck_gen_wasm/modules/ai/bundled`. Т.е. из этой удалённой github-папки при запуске приложения необходимо извлекать всё содержимое, где:
- <mode-name>.json5 - это конфигурации для доступных ai моделей;
- ai-help-<en|ru>.md - пользовательская справка для создания новых конфигураций;
- edit-game-pt-<en|ru>.md - шаблон промпта для редактирования игры
- create-game-pt-<en|ru>.md - шаблон промпта для создания игры

Отдельно отмечу, что файлы `edit-game-pt-<en|ru>.md` и `create-game-pt-<en|ru>.md` должны помещаться в папку help в LFS, что пользователь имел возможность менять текст промптов при запуске агентского цикла.

### №2
Ручные тестовые сценарии, которые сейчас базируются на 3 простых вопросах с ожидаем какого-либо ответа, необходимо проверить на  модели Gemini 3.1 Flash-Lite (сейчас её файл конфигурации находится в `projects\deck_gen_wasm\modules\ai\bundled\gemini-3.1-flash-lite.json5`) с тестовым ключом `???`.

О ключе для тестирования (пример живого теста, можешь переформулировать):
```
Я создал этот ключ специально для тестов (он временный), поэтому можешь его спокойно использовать.
Необходимо добиться корректной работы тестов на целевой модели (ответы должны быть адекватными а не ошибка вроде `error 400`).
На время своей проверки используй ключ прямо в коде, что исключить необходимость ручного ввода. Когда убедишься, что тесты правильные, верни ввод ключа пользователем в консоли.
```
