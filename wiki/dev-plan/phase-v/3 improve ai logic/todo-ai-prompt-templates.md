# Задача на разработку: Промпты агента — в bundled markdown
Вынести шаблоны `request_text` и `system_prompt` из `engine.rs` в файлы и выбрать их по типу запроса и локали UI.

Зачем: тексты промптов нельзя держать захардкоженными в Rust; EN/RU правятся как документы.

Ожидаемый результат: в `modules/ai/bundled` четыре файла; `engine.rs` подставляет плейсхолдеры и не содержит английских абзацев правил/задачи. Help-файлы VFS в этой задаче не переименовывать.

## Функциональные требования

### Файлы (имена фиксированы)
В `projects/deck_gen_wasm/modules/ai/bundled/`:

1. `create-game-pt-en.md` / `create-game-pt-ru.md` — создание новой игры (`CreateGame`).
2. `edit-game-en.md` / `edit-game-ru.md` — правка существующей (`EditGame`).

Каждый файл покрывает то, что сейчас делают **оба** `system_prompt` и `request_text` для своего сценария (правила агента + формулировка задачи).

Выбор файла: вид `AiRequest` × `locale::get_active_locale()` (`en`/`ru`).

### Подстановки
В шаблоне плейсхолдеры (достаточно текстовой замены, без шаблонизатора):

- `{user_prompt}` — промпт пользователя
- `{game}` / `{file}` — для edit (для create можно не использовать)
- `{game_help}` — тело game-help из VFS по **уже существующему** conf-пути (сейчас `game-help.md` или уже `help/game-help-<locale>.md`, если задача локализации help сделана). Не хардкодить имя файла второй раз.
- `{tools}` — декларации инструментов, как сейчас в system prompt

Правила агента (prepare_html, запрет `_autogenerated`, не PDF/PNG, читать help, остановиться с кратким summary) должны остаться в тексте шаблона, не в Rust.

EN: перенести текущий английский смысл 1:1. RU: перевод тех же инструкций.

После выноса в `engine.rs` не оставлять дубли исходных строк.

### Не входит
- Папка VFS `help/`, install help, json5 моделей, модалка ключа, RPM, 503.
- Не класть эти шаблоны в VFS — только compile-time `include_str` из `bundled`.

## Scope
- `projects/deck_gen_wasm/modules/ai/bundled/create-game-pt-en.md`
- `projects/deck_gen_wasm/modules/ai/bundled/create-game-pt-ru.md`
- `projects/deck_gen_wasm/modules/ai/bundled/edit-game-en.md`
- `projects/deck_gen_wasm/modules/ai/bundled/edit-game-ru.md`
- `projects/deck_gen_wasm/modules/ai/src/engine.rs` — загрузка шаблона вместо `request_text` / `system_prompt`
- зависимость `deck_gen_wasm_locale` у `ai` — только если её ещё нет и иначе не взять текущую локаль; не тащить leptos

Тест: выбор create vs edit и en vs ru (хотя бы что подставляется `{user_prompt}` / `{file}` и непустой шаблон). Без сети.

## Проверка корректности решения

**Тесты native:** CreateGame+en содержит смысл «new card game» и user prompt; EditGame подставляет game/file; ru-файл не равен en.

**Ручной смоук:** Create и Edit на EN и RU — в `ai-models/log/*.md` виден шаблон выбранного языка, не смесь, game-help вложен.
