# Задача на разработку: Clear удаляет только игры
Кнопка Clear рабочей области должна удалять не всё дерево VFS, а только содержимое папки `games/` (файлы игр).

Зачем: help, `ai-models/` (ключи, логи) и прочие корневые файлы не должны пропадать вместе с играми.

Ожидаемый результат: `Workspace::clear` снимает всё под `games/`, оставляет остальной VFS, закрывает вкладки/выделение связанные с играми, персистит оставшееся. Confirm-текст говорит, что удаляются игры, а не вся сессия.

## Функциональные требования
- Удаляется **только** то, что находится в папке `games` (все игры, `games/conf.json5` и любые другие дети `games/`).
- Не трогать: `user-help.md` / `game-help.md` / `help/**`, `ai-models/**`, любые другие корневые файлы и папки.
- Папку `games/` после очистки оставить существующей и пустой (если API VFS удобнее удалить узел `games` целиком — сразу создать пустой `games/`).
- Не обнулять весь `Workspace` как сейчас (`vfs = default`, сброс catalog/tabs/expanded скопом).
- Вкладки, selection, multi-select, copy plan, expanded, draft, относящиеся к путям под `games/` — забыть (уже есть `forget_path`).
- Catalog / `temp_vfs` не сбрасывать (это не persist-игры).
- После очистки — persist session + binaries оставшегося дерева (не пустого VFS).
- Локаль: обновить confirm/tooltip/status так, чтобы пользователь понимал: удаляются игры, действие необратимо. Help и AI-конфиги остаются.
- Не менять AI-цикл, модалки промпта, HTTP.

## Scope
- `projects/deck_gen_wasm/modules/workspace/src/actions.rs` — `clear`
- при необходимости `projects/deck_gen_wasm/modules/workspace/src/state.rs` (`forget_path`)
- `projects/deck_gen_wasm/modules/locale/src/keys.rs`, `dict.json5` — тексты Clear
- native-тест на `clear`, если его можно написать без WASM/Leptos; иначе логика в `clear` + ручной смоук. Не расползаться в `ui`, кроме уже завязанных ключей локали (Confirm в `activity.rs` ключи уже читает — сам файл не обязателен, если тексты только в dict).

Не трогать: `ai`, `conf` schema моделей, help-install.

## Проверка корректности решения

**Тест (предпочтительно native):** VFS с `games/a/game.json5`, `user-help.md`, `ai-models/x.json5` → после clear нет файлов под `games/` (кроме пустой папки), help и ai-models на месте.

**Ручной смоук**
1. Есть игра + ключ в json5 + открытый help → Clear → confirm → игр нет, help и `ai-models/` есть, сессия после reload та же.
2. Открытая вкладка файла игры закрылась; вкладка help осталась, если была.
3. Load Local Games / Create with AI после clear работают.
