# Цель
Необходимо добавить возможность использования AI при создании карточных игры через `deck_gen_wasm`.
Под возможностями подразумевается следующее:
1. запрос на создания полностью новой игры
2. запрос на создание/редактирование карточной колоды
3. запрос на создание/редактирование лицевой и обратных сторон карточных колод

Базово, всё множество требуемых возможностей упирается в предоставлении AI через API следующих возможностей:
1. просмотр VFS содержащей загруженные игры
2. создание и редактирование содержащихся в ней файлов по правилами создания игры (таковые правила необходимо получать посредством загрузки файла https://github.com/AlexeyPerestoronin/Deck-Games/blob/master/README.md → достаточно положить его в корень VFS при загрузке/перезагрузке приложения, если его там ещё нет).

# Задача
Проанализируй код deck_gen_wasm и внеси свои предложения как может быть реализована поставленная цель.
Раздели предложения относительно backend (движок, логике) и frontend (ui-элементы, процесс работы пользователя) частей.
Ожидаю от тебя несколько предложений с сравнительной таблицей.

Обязательные моменты:
- backend часть должна быть оформлена в виде отдельного модуля с изолированным api
- backend должен обладать возможностью работать с различными моделями (Gemini, DeepSeek, Grok) и переключать их желанию пользователя
- - использоваться должен только бесплатные модели
- - настройки конкретной модели должны находиться в файле конфигурации
