# Задача: «test task»
Необходимо проанализировать python код и произвести его рефакторинг.
Весь необходимый код находится в папке `Tools`.

***

# Дополнительные указания
1. Запускать код не нужно (Я САМ).
2. Для изменения содержимого файлов используй `patch` (есть в списке доступных shell команд).
3. О результатах отпишись в чате.

## Как правильно писать код:
1. Изменения в коде должны быть минимальными.
2. Запрещено менять существующую архитектуру.
3. этап-1: решить поставленную задачу и убедиться в её работоспособности;
   - первичный код необходимо писать простой, понятный и прямолинейный, без сложных абстракций;
   - если логика кода сложная, но позволяет написать простые unit-тесты для проверки, их надо написать;
4. этап-2: когда поставленная задача будет решена, код, созданный и зафиксированный на этапе-1, необходимо отрефакторить согласно правилам записанным в `WiKi\rules\refactoring-base.md`
   - при организации кода придерживайся стиля той кодовой базы в которую вносишь изменения;
5. первый и второй этапы должны делаться раздельно, но в рамках одного промпта (решение → проверка → рефакторинг).
