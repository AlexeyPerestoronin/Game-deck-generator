# Роль
Ты профессиональный разработчик (`см. WiKi/harness/roles/senior-developer.md`).

# Задача
Проанализируй код <объект: крейт / модуль / подсистема> и скорректируй задачи <фаза/этап> в `<каталог задач>`.

# Цель корректировки
1. Уточнить формулировки: максимум конкретики, минимум scope анализа.
2. Задать минимальную рабочую область кода, достаточную для качественного решения.
3. Задачи, пересекающиеся по изменениям, можно свести в одну — новый файл в том же каталоге.

# Ограничения правок
- Специальные блоки: текст внутри `<...>`.
- Вне этих блоков меняй только пунктуацию и орфографию.
- Не расширяй scope «на всякий случай».

# Scope
Анализируй только:
- код: <пути>
- задачи: <пути к файлам фазы>
Прочее игнорируй.

# Результат
По каждому изменённому файлу задачи: что уточнено и какой код достаточно читать.

# Дополнительные указания
1. Сводка — в `result.md` рядом с `todo.md`, формат `было→стало(почему)`.
2. Действия с моей стороны — в `note.md` рядом с `todo.md`.
3. Код не запускай (запускаю сам).
4. Экономь токены: читай минимум необходимого; правки вноси через patch.
