# Доработка №3: чёрные карты на белом PDF (`deck_gen_wasm`)

Симптом после №2: viewer живой, лист белый, навигация есть, но карты — сплошные чёрные прямоугольники.

## Причина

- было: PDF через `iframe.srcdoc` + белая оболочка + `<embed src=blob type=application/pdf>` → стало: так нельзя (почему: вложенный embed рисует бумагу и тулбар, а растровые XObject карт — JPEG с html→pdf — даёт чёрные плашки).
- было: до split карты были видны при `iframe.src = blob:` → стало: возвращаем этот путь (почему: это тот показ, который уже работал).

## Показ PDF

- было: `prop:srcdoc=pdf_light_shell(blob)` → стало: `prop:src=blob` как в исходном `PdfPreview`.
- было: `pdf_light_shell` + escape URL + тесты оболочки → стало: функция удалена (почему: YAGNI, оболочка и есть регресс карт).
- было: `Show` пока blob не готов — оставили (почему: iframe монтируется уже с URL, без пустого src).
- было: белый `.preview-host` flex — оставили (почему: размер панели, не вложенный plugin).

## CSS

- было: комментарий про чёрный холст страницы из `color-scheme`/`absolute` → стало: запрет тех же свойств, потому что они плюс вложенный embed дают чёрные **карты** (плагин отдельно красит изображения).
- было: flex fill без absolute/`color-scheme` — без изменений (нужно и для тулбара, и чтобы не повторить №1–2).

## Что не трогали

- keyed `For` тела панели (переключение вкладок из №1).
- split, auto-open preview.

## Рефакторинг (этап-2)

- было: отдельная «светлая оболочка» как абстракция от тёмной IDE → стало: убрана (KISS: прямой blob iframe, один модуль preview без лишней HTML-сборки).
- было: шапка модуля про shell → стало: явно сказано не класть PDF в srcdoc/embed.

## Тесты

- было: 57 тестов (два на оболочку) → стало: 55 ok, `cargo test -p deck_gen_wasm --offline`.
