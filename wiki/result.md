# Split for preview (`deck_gen_wasm`)

В ТЗ первая фраза путает стороны; реализация следует детальным пунктам и `todo-right-side-preview.md`: слева файлы, справа preview.

## ActivityBar

- было: слева save / ZIP / new / load / HTML / PDF / clear → стало: после PDF кнопка `split for preview` (почему: однократное нажатие включает split, повторное выключает).
- было: кнопки только серые, синий акцент лишь на focus → стало: класс `.activity-btn.active` красит иконку и левую кромку в `--accent` (почему: ТЗ — активная кнопка синяя).
- было: нет глифа «две колонки» → стало: `SplitPreviewIcon` рядом с остальными 16×16.

## Рабочая область

- было: один `<main class="editor">` на всю третьи колонки IDE → стало: при split сетка `.editor-split` 1fr+1fr, две панели `EditorPane` (почему: левая — правки, правая — preview).
- было: одна лента вкладок `tabs` + `active_tab` → стало: пока split выключен — как раньше; пока включён — `tabs`/`active_tab` слева, `preview_tabs`/`active_preview_tab` справа.
- было: пустая панель одна фраза про explorer → стало: справа отдельный empty «No preview open.» (почему: ТЗ — правая половина может быть без вкладок).

## Включение split

- было: все Edit и Preview в одном списке → стало: `partition_tabs` раскладывает Edit налево, Preview направо, порядок внутри каждой ленты сохраняется.
- было: некуда деть «активную» вкладку при двух панелях → стало: `active_after_split` оставляет текущую вкладку в своей половине, во второй берёт первую (почему: не прыгать фокусом).
- было: нет preview → правой половины не существовало → стало: правая панель пустая, без вкладок.

## Открытие файла при активном split

- было: `open_tab` всегда кладёт вкладку в общий список и делает её active → стало: Preview идёт в правую ленту; Edit — в левую.
- было: preview только через ПКМ «Preview» → стало: если файл html/md/pdf/картинка и правой вкладки ещё нет, она открывается сама (`should_auto_open_preview`) (почему: пункт ТЗ про автоматический preview).
- было: повторный preview того же пути создавал бы дубликат → стало: вкладка не добавляется, если уже есть.

## Выключение split

- было: нечего сливать → стало: `merge_split_tabs` — сначала левые вкладки, затем правые без дубликатов; активной остаётся левая (`active_after_merge`) (почему: левые файлы возвращаются в общий пул; правые preview не выбрасываются, иначе toggle терял бы вкладки).

## Соседние операции

- было: close/activate/forget/rename/clear знали один список → стало: close/activate смотрят нужную ленту; delete чистит обе (`forget_tabs`); rename переписывает пути в обеих; clear обнуляет и preview-ленту.

## Файлы

- было: логика вкладок только в `workspace/mod.rs` + один Editor → стало: чистые правила в `workspace/split.rs` (тесты без DOM); `impl Workspace` там же, по образцу `commands.rs`.
- было: `is_previewable` спрятан в меню → стало: одна функция в `split.rs`, меню её переиспользует.
- было: разметка панели внутри `editor/mod.rs` → стало: `editor/pane.rs` — одна половина, `Editor` только выбирает 1 или 2.

## Тесты

- было: 43 теста, split не покрыт → стало: 54 ok (`cargo test -p deck_gen_wasm --offline`): previewable-расширения, partition/merge, active после on/off, auto-open, close-neighbor, forget пути.
- было: assert лейбла `copy`/`past` в нижнем регистре при фактических `Copy`/`Past` → стало: assert совпадает с константами меню (иначе крейт не зелёный).

## Рефакторинг (этап-2)

- было: split-методы жили в `mod.rs` рядом с create/select → стало: ответственность «две панели и маршрутизация вкладок» в `split.rs` (KISS, один модуль — одна задача).
- было: Editor раздувался match’ем тела панели → стало: `pane.rs` + тонкий `mod.rs`.
- было: без шапок у новых файлов → стало: module docs и rustdoc у публичных кнопок, полей Workspace, `toggle_split_preview` / `open_tab`.
