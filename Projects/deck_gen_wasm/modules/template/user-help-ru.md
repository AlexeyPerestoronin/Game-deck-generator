# Генератор колод (браузер)

Этот сайт — рабочая область в браузере для карточных колод. Файлы живут в памяти и в хранилище этого браузера. Аккаунта нет, серверной копии вашей работы тоже нет.

## Что здесь делать

1. Начните с примера игры или загрузите уже существующую папку.
2. Правите данные JSON5, представления HTML/SCSS и заметки Markdown в дереве.
3. Соберите HTML-превью карт, затем PDF-листы для печати.
4. Скачайте ZIP, если файлы нужны на диске.

## Раскладка

- Левая полоса — действия (наведите на кнопку; подсказка появится после короткой паузы).
- Середина — дерево файлов.
- Справа — редактор или превью.

## Левые кнопки (сверху вниз)

- **Сохранить** — записать рабочую область в этот браузер. После перезагрузки она восстановится.
- **Скачать** — сохранить всё как `workspace.zip`.
- **Новая игра** — скопировать шаблон `new-game` с GitHub `master` в `games/`.
- **Загрузить игру** — выбрать папку на диске. Она копируется в `games/`. Допустимые файлы: `md`, `json`, `json5`, `html`, `scss`.
- **prepare_html** — собрать HTML-превью для каждой колоды (`_autogenerated/`).
- **prepare_pdf** — собрать PDF карт и двусторонние листы A4 (сначала HTML).
- **Очистить** — стереть рабочую область в этом браузере. Отменить нельзя.

## Дерево

- **+ Файл** / **+ Папка** — создать в выбранной папке (или в родителе выбранного файла).
- Щёлкните файл, чтобы править его.
- Правый щелчок по файлу: **Предпросмотр** (html, md, pdf), Переименовать, Удалить.
- PDF в редакторе показывает только размер; чтобы посмотреть содержимое, используйте **Предпросмотр**.

## Типичный порядок работы

1. **Новая игра** или **Загрузить игру**.
2. Правите `games/<id>/vars/*.json5` (общие значения) и `decks/**/data.json5` (карты).
3. Правите `views/*.html` и `*.scss` для лицевой и оборотной стороны.
4. **prepare_html** — откройте `_autogenerated/**/preview.html` через Предпросмотр.
5. **prepare_pdf** — печатайте из PDF рядом с этими HTML-файлами.
6. **Сохранить** здесь и/или **Скачать** ZIP.

## Устройство примера игры

В `games/<id>/`:

- `game.json5` — идентификатор игры (должен совпадать с именем папки).
- `vars/` — значения для `${game:...}` и `${card:...}`.
- `decks/` — по папке на колоду, в каждой `data.json5`.
- `views/` — шаблоны, указанные в `view.face` / `view.back`.

Имя колоды `name` должно быть `{game-id}.{path.from.decks}` (пример: `new-game.deck-1st`).
Плейсхолдеры подставляются до разбора JSON5. `$s{words}` удерживает фразу на одной строке.

## Замечания

- Работа остаётся в этом браузере, пока вы её не скачаете.
- PDF не хранятся в localStorage (слишком большие); после перезагрузки соберите их снова.
- Этот файл — `help/user-help-ru.md` (поставляется с приложением; открывается в превью, если нет открытых вкладок).
