# How to build a card game in this workspace

This file is for the AI agent (and humans) working on games under `games/`.

## Layout

Each game is a folder that contains `game.json5`:

```
games/<id>/
  game.json5          # game id; must match the folder name `<id>`
  vars/               # shared values for ${game:...} and ${card:...}
  decks/              # one folder per deck, each with data.json5
  views/              # HTML and SCSS templates named in view.face / view.back
  rules/              # optional notes, posters, info.json5
```

Do **not** write files under any `_autogenerated/` folder. Those files are produced only by `prepare_html`.

## game.json5

- Holds the game id.
- The id **must** equal the folder name (`games/poker` → id `poker`).

## Decks

- Path: `games/<id>/decks/**/data.json5` (nested folders are allowed).
- Deck `name` must be `{game-id}.{path.from.decks}`.
  - Example: folder `games/new-game/decks/deck-1st/` → name `new-game.deck-1st`.
- Cards are rows in `data.json5`, not images.
- Face and back templates: `view.face` and `view.back` (file names under `views/`).

## Views

- `games/<id>/views/*.html` and `*.scss`.
- Placeholders are substituted before JSON5 is parsed.
- `$s{words}` keeps a phrase on one line.

## vars/

- Shared JSON5 values referenced from cards and views.

## Checking work

After creating or editing sources, run **prepare_html**. It writes HTML previews into `games/<id>/_autogenerated/**` (for example `preview.html`, `face.html`, `back.html`). If it reports errors, fix the sources and run it again.

Do not generate PDF or PNG. Cards are HTML + JSON5.

## New game

Pick a short folder id (`games/<id>/`). Create `game.json5`, at least one deck `data.json5`, and the views it names. Then `prepare_html`.
