# Как собрать карточную игру в этой рабочей области

Этот файл — для AI-агента (и людей), которые работают с играми в `games/`.

## Устройство

Каждая игра — папка, в которой есть `game.json5`:

```
games/<id>/
  game.json5          # идентификатор игры; должен совпадать с именем папки `<id>`
  vars/               # общие значения для ${game:...} и ${card:...}
  decks/              # по папке на колоду, в каждой data.json5
  views/              # HTML- и SCSS-шаблоны, указанные в view.face / view.back
  rules/              # необязательные заметки, афиши, info.json5
```

**Не** пишите файлы ни в какую папку `_autogenerated/`. Эти файлы создаёт только `prepare_html`.

## game.json5

- Хранит идентификатор игры.
- Идентификатор **должен** совпадать с именем папки (`games/poker` → id `poker`).

## Колоды

- Путь: `games/<id>/decks/**/data.json5` (вложенные папки допустимы).
- Имя колоды `name` должно быть `{game-id}.{path.from.decks}`.
  - Пример: папка `games/new-game/decks/deck-1st/` → имя `new-game.deck-1st`.
- Карты — строки в `data.json5`, не картинки.
- Шаблоны лица и оборота: `view.face` и `view.back` (имена файлов в `views/`).

## Представления

- `games/<id>/views/*.html` и `*.scss`.
- Плейсхолдеры подставляются до разбора JSON5.
- `$s{words}` удерживает фразу на одной строке.

## vars/

- Общие значения JSON5, на которые ссылаются карты и представления.

## Проверка работы

После создания или правки исходников запустите **prepare_html**. Он записывает HTML-превью в `games/<id>/_autogenerated/**` (например `preview.html`, `face.html`, `back.html`). Если есть ошибки — исправьте исходники и запустите снова.

Не генерируйте PDF или PNG. Карты — это HTML + JSON5.

## Новая игра

Выберите короткий идентификатор папки (`games/<id>/`). Создайте `game.json5`, хотя бы одну колоду `data.json5` и указанные в ней представления. Затем `prepare_html`.
