# Game Deck Generator

Генератор карточных колод для настольной игры: из данных карт и шаблонов сторон получаются превью для проверки макета и листы для двусторонней печати.

Игра живёт в папке: общие переменные, колоды (`data.json5`) и виды лица/рубашки. Сборка пишет HTML и PDF в `_autogenerated/`.

# Способы использования:

**CLI.** Из корня репозитория:

```
deck_gen list
deck_gen list --json
deck_gen html
deck_gen html --name monopoly.professions.level_0
deck_gen html --name professions.level_0
deck_gen pdf --name monopoly.events.positives.lucky_day
deck_gen pdf --name monopoly.events.positives.lucky_day --duplex long-edge
```

- `list` — имена колод (полное имя, имя относительно игры по умолчанию или префикс).
- `html` — лицо, рубашка и `preview.html` в `_autogenerated/`.
- `pdf` — то же плюс PDF карт и A4-лист duplex (`long-edge` / `short-edge`). Нужен установленный Chrome или Edge.

**WEB.** Редактор в браузере: [Game Deck Generator на GitHub Pages](https://alexeyperestoronin.github.io/Game-deck-generator/).

1. «New game» или «Load Game» — шаблон либо своя папка игры.
2. Правите `vars/`, `decks/**/data.json5` и `views/`.
3. «prepare_html» — смотрите `_autogenerated/**/preview.html`.
4. «prepare_pdf» — карты и A4-листы рядом с HTML.
5. «Save» в этом браузере и/или «Download» ZIP.
