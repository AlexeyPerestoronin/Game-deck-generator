# Game Deck Generator

**Универсальный генератор карточных колод для настольных игр:**
- без ограничений на количество колод и карт в них;
- возможность гибкой настройки дизайна лицевой и обратной стороны колод;
- возможность использование локальных и глобальных переменных в колодах и картах;
- возможность двусторонней А4-печати через подготовленный pdf.

# Способы использования:

## **CLI.** Из корня репозитория:

```
./Game-deck-generator>deck_gen.exe --help
Generate card decks from JSON5 + templates

Usage: deck_gen.exe <COMMAND>

Commands:
  list  Print known deck names
  html  Render face/back/preview HTML
  pdf   Render HTML, then card PDFs and an A4 duplex sheet (needs local Chrome)
  help  Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
```

- `list` — имена колод (полное имя, имя относительно игры по умолчанию или префикс).
- `html` — лицо, рубашка и `preview.html` в `_autogenerated/`.
- `pdf` — то же плюс PDF карт и A4-лист duplex (`long-edge` / `short-edge`). Нужен установленный Chrome или Edge.

## **WEB.** Редактор в браузере: [Game Deck Generator на GitHub Pages](https://alexeyperestoronin.github.io/Game-deck-generator/).

1. «New game» или «Load Game» — шаблон либо своя папка игры.
2. Правите `vars/`, `decks/**/data.json5` и `views/`.
3. «prepare_html» — смотрите `_autogenerated/**/preview.html`.
4. «prepare_pdf» — карты и A4-листы рядом с HTML.
5. «Save» в этом браузере и/или «Download» ZIP.

# Примеры работ:

Галерея с выбором колоды и пролистыванием лица/рубашки: откройте [examples.html](examples.html) в браузере.
