# Deck generator (browser)

This site is an in-browser workspace for card-game decks. Files live in memory and in this browser’s storage. There is no account and no server copy of your work.

## What you do here

1. Start from the sample game, or load a folder you already have.
2. Edit JSON5 data, HTML/SCSS views, and Markdown notes in the tree.
3. Generate HTML card previews, then PDF sheets for print.
4. Download a ZIP if you want the files on disk.

## Layout

- Left strip — actions (hover a button; a tooltip appears after a short delay).
- Middle — file tree.
- Right — editor or preview.

## Left buttons (top to bottom)

- **Save** — write the workspace into this browser. A reload restores it.
- **Download** — save everything as `workspace.zip`.
- **New game** — copy the `new-game` template from GitHub `master` into `games/`.
- **Load Game** — pick a folder on disk. It is copied under `games/`. Allowed files: `md`, `json`, `json5`, `html`, `scss`.
- **prepare_html** — build HTML previews for every deck (`_autogenerated/`).
- **prepare_pdf** — build card PDFs and A4 duplex sheets (run HTML first).
- **Clear** — wipe this browser workspace. Cannot be undone.

## Tree

- **+ File** / **+ Folder** — create under the selected folder (or the parent of the selected file).
- Click a file to edit it.
- Right-click a file: **Preview** (html, md, pdf), Rename, Delete.
- A PDF in the editor only shows its size; use **Preview** to view it.

## Typical pipeline

1. **New game** or **Load Game**.
2. Edit `games/<id>/vars/*.json5` (shared values) and `decks/**/data.json5` (cards).
3. Edit `views/*.html` and `*.scss` for face and back.
4. **prepare_html** — open `_autogenerated/**/preview.html` with Preview.
5. **prepare_pdf** — print from the PDFs next to those HTML files.
6. **Save** here and/or **Download** a ZIP.

## Sample game layout

Under `games/<id>/`:

- `conf.json5` — game id (must match the folder name).
- `vars/` — values for `${game:...}` and `${card:...}`.
- `decks/` — one folder per deck, each with `data.json5`.
- `views/` — templates named in `view.face` / `view.back`.

Deck `name` must be `{game-id}.{path.from.decks}` (example: `new-game.deck-1st`).
Placeholders are substituted before JSON5 is parsed. `$s{words}` keeps a phrase on one line.

## Notes

- Work stays in this browser until you download it.
- PDFs are not stored in localStorage (too large); generate them again after a reload.
- This file is `user-help.md` at the workspace root (shipped with the app; preview if no tab is open).
