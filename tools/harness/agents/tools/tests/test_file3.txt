Теорема: Множество всех простых чисел является бесконечным.
Доказательство проведем классическим методом от противного.
Этот метод впервые был предложен древнегреческим математиком Евклидом.
Сформулируем основное допущение для нашего математического доказательства.
Предположим, что множество простых чисел является конечным.
Обозначим это конечное множество латинским символом P.
Тогда мы можем полностью перечислить все элементы этого множества.
Пусть p_1, p_2, ..., p_n — все существующие в мире простые числа.
Здесь индекс n представляет собой общее количество простых чисел.
Каждее p_i является простым числом по нашему исходному определению.
Никаких других простых чисел в рамках данного допущения не существует.
Теперь сконструируем новое натуральное число, обозначим его буквой N.
Определим число N как произведение всех известных простых чисел плюс один.
Математически это выражение можно записать следующим образом:
N = (p_1 * p_2 * ... * p_n) + 1.
Очевидно, что число N строго больше единицы, так как p_i >= 2.
Следовательно, N является натуральным числом, строго большим 1.
По основной теореме арифметики, любое натуральное число имеет делители.
В частности, каждое число больше 1 делится по крайней мере на одно простое.
Пусть q — некоторый простой делитель нашего сконструированного числа N.
Поскольку мы предположили, что p_1, ..., p_n — это ВСЕ простые числа.
То число q обязательно должно совпать с одним из чисел из списка P.
То есть существует такой индекс k (где 1 <= k <= n), что q = p_k.
Рассмотрим теперь процесс деления числа N на это простое число p_k.
С одной стороны, по определению делителя, N делится на p_k без остатка.
С другой стороны, подставим формулу для вычисления числа N.
N = (p_1 * p_2 * ... * p_k * ... * p_n) + 1.
Первое слагаемое в этой сумме является произведением, содержащим p_k.
Значит, произведение (p_1 * p_2 * ... * p_n) делится на p_k нацело.
Когда мы делим сумму на число, мы делим каждое слагаемое.
При делении N на p_k мы получаем целое частное и некоторый остаток.
В данном конкретном случае остаток от деления равен единице.
Таким образом, число N не может делиться на p_k без остатка.
Мы пришли к очевидному и неизбежному логическому противоречию.
Одно и то же число N одновременно делится и не делится на p_k.
Данное противоречие возникло из-за нашего исходного предположения.
Следовательно, наше предположение о конечности множества неверно.
Значит, исходное утверждение фундаментальной теоремы истинно.
Множество простых чисел никак не может быть конечным.
Оно содержит бесконечно много элементов. Что и требовалось доказать.
Дополнительно рассмотрим свойства делимости в данном контексте.
Если число делится на два последовательных числа, то это невозможно для >1.
В нашем случае произведение и число N являются последовательными.
Их разность строго равна единице, что полностью исключает общий делитель.
