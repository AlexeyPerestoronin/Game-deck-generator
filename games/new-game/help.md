# Как устроена игра

Шаблон `new-game` — это одна игра: общие переменные, несколько колод и HTML-шаблоны сторон карты. Имя игры в `conf.json5` и имя папки в `games/` должны совпадать с префиксом поля `name` в файлах колод.

## Папки

- `vars/` — общие JSON/JSON5 файлы игры. Имя файла без расширения становится префиксом в плейсхолдере: `game.json5` → `${game:...}`, `card.json5` → `${card:...}`.
- `decks/` — колоды. Каждая колода живёт в своей папке и содержит `data.json5` (допустимо и `data.json`).
- `views/` — шаблоны лица и рубашки, на которые ссылается поле `view` в колоде.

Путь колоды относительно `decks/` превращается в суффикс имени. Пример: `decks/deck-1st/data.json5` → `new-game.deck-1st`.

## `data.json5`

Обязательные поля:

- `name` — полное имя колоды, должно совпадать с `{id-игры}.{путь.от.decks}`.
- `view.face` / `view.back` — имена файлов в `views/`.
- `deck` — поля, общие для всех карт (название, размеры, подпись игры).
- `cards` — список карт. Ключи внутри карты нормализуются: `life-effects` и `life_effects` — одно и то же.

Размеры карты обычно задают в `deck` через `${card:width_mm}` и `${card:height_mm}`, чтобы все колоды делили один формат из `vars/card.json5`.

## Плейсхолдеры `${...}`

Подстановка идёт по тексту JSON5 до разбора файла.

- `${game:name}` — поле `name` в `vars/game.json5` (или `.json`).
- `${card:sample_cost}` — поле из `vars/card.json5`.
- Можно смешивать оба файла в одной строке: `${game:name}` и `${card:width_mm}`.
- Карта может не использовать переменные вообще — тогда в тексте остаётся обычная строка.
- `${vars.x}` — локальный объект `vars` внутри того же `data.json5`, если он есть.
- `$s{фраза с пробелами}` — неразрывные пробелы, чтобы подпись не переносилась.

Файлы переменных ищутся сначала в `vars/` рядом с `data.json5`, затем в `vars/` игры.

В этом шаблоне:

- `deck-1st` — 2 карты: без переменных и только из `card.json5`.
- `deck-2nd` — 4 карты: без переменных, только `card.json5`, только `game.json5`, оба файла сразу.

## Как править колоду

1. Меняйте `vars/*.json5`, если значение общее для нескольких колод или карт.
2. В `cards` пишите конкретный текст карты; плейсхолдеры подставляются при сборке.
3. Новую колоду копируйте как папку рядом с `deck-1st` и поправьте `name` под новый путь.
4. Новую игру копируйте как папку в `games/` и заведите для неё запись в корневом `conf.json5`.
